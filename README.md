# 用户多元异质特征表示学习系统

跨平台（Twitter + Weibo）用户属性预测。TF-IDF + 显式信号 + RandomForest。

## 两个任务

| 任务 | 入口 | 说明 |
|------|------|------|
| **属性预测** | `python main.py` | 7 项用户属性多任务分类，召回率≥75%、准确率≥80% |
| **U13 缺失补全** | `python U13_tasks/main.py` | 数量级分桶均值填充，MAE 评估，补全 vs 基线对比 |

---

## 处理流程

### 属性预测流水线（main.py）

```
labeled_data.csv ──→ [缓存加载] ──→ train/test 切分 ──→ bootstrap 扩充
                                                              │
┌─────────────────────────────────────────────────────────────┘
│
├─ 静态编码 (454d): TF-IDF SVD + 主题信号 + 职业信号 + 子兴趣信号 + 数值
├─ 动态编码 (64d):  短/中/长三尺度行为信号
├─ 社交编码 (64d):  邻域/社区/全局结构信号
│
└─→ 门控融合 (582d) ──→ [异常检测+修正] ──→ [7任务预测] ──→ 三场景评估
```

### U13 缺失补全（U13_tasks/main.py）

```
原始 CSV ──→ 注入 15% 缺失 ──→ 对数分桶 → 同桶均值填充 ──→ MAE vs 基线
```

## u13

```
原始数据（Twitter + Weibo）
    │
    ▼
Step 1: 数据清洗
    │  ├─ 数值列标准化（to_numeric → fillna → clip）
    │  └─ 衍生特征计算（log变换、ff_ratio等）
    │
    ▼
Step 2: 模拟缺失
    │  └─ 从18,698用户中随机选15%行，每列独立注入NaN
    │     7列 × 15% ≈ 19,628个缺失值
    │
    ▼
Step 3: 方法一·数量级分桶填充
    │  ├─ 对 target_col 选一个辅助列 aux_col
    │  ├─ aux_col 按 log10 分桶（每半量级一桶）
    │  └─ 缺失值 = 同桶内非缺失用户的均值
    │
    ▼
Step 4: 方法二·kNN 加权填充（推荐）
    │  ├─ 将所有特征标准化（自动检测偏态列做 log 变换）
    │  ├─ 对每个缺失用户，在完整数据中找 k 个最近邻
    │  ├─ 距离 = 标准化空间中的欧几里得距离（仅用有效维度）
    │  ├─ 排除自身（防止数据泄露）
    │  └─ 缺失值 = 邻域加权平均（权重 = 距离倒数）
    │
    ▼
Step 5: 效果评估
    ├─ 对比：填充值 vs 真实值
    ├─ 指标：MAE、RMSE
    └─ 基线：全局均值填充
```

### u13两种方法原理对比

| 方面 | MagnitudeBucketing | kNN Imputer ⭐ |
|------|-------------------|---------------|
| **分组方式** | 单维对数量级分桶 | 多维空间距离度量 |
| **信息利用** | 只用 1 个辅助列 | 利用**全部**有效特征 |
| **填充方式** | 桶内简单均值 | 距离加权平均 |
| **尺度处理** | 无 | 自动 log 变换 + 标准化 |
| **粒度** | 粗（半量级一桶） | 细（连续空间最近邻） |
| **预期 MAE** | 略优于基线 | **显著优于基线** |

```

```

然后两种方法的对比表格：

```
  followers_count:
    MagnitudeBucketing    MAE=2139117    Baseline=2187743     +2.2%
    kNN Imputer           MAE=331163     Baseline=2216511    +85.1%
```

- **MAE**：平均绝对误差（越小越好）
- **Baseline**：全局均值填充的 MAE
- **Improve**：`(Baseline - MAE) / Baseline`，正数表示比基线好

最后给出最佳方法结论。

## u13 10 个样本详解

以下从 18,698 个用户中抽取 10 个典型样本，展示 kNN 填充的表现。

### u13说明

- **缺失列**：当前模拟中只有 `followers_count` 被设为缺失
- **辅助特征**：friends_count、statuses_count 等保持完整，用于找近邻
- **填充误差** = |真实值 − kNN 填充值|

### u13样本表

| # | 平台 | 真实粉丝 | kNN填充 | 误差 | 好友数 | 发帖数 | 分析 |
|---|------|---------|---------|------|--------|--------|------|
| 1 | Twitter | 9,943,803 | 797,609 | **9M** | 0 | 0 | 超级大V（近千万粉），但好友和发帖均为0。kNN找到的邻居没有同样量级的，误差很大。**长尾分布下极值用户难以填充。** |
| 2 | Weibo | 23,561,144 | 870萬 | **15M** | 111 | 33,733 | 也是超大型号，但好友/发帖适中。kNN低估了粉丝数。 |
| 3 | Twitter | 549,064 | 4,902,802 | **4.4M** | 29 | 29,718 | 有发帖数但没好友。kNN找到了发帖量大但粉丝更多的用户。 |
| 4 | Weibo | 236 | 8,361,273 | **8.4M** | 243 | 7,457 | 真实值很低（236粉），但好友和发帖普通。kNN高估严重——说明**少量好友+中量发帖对应着大量粉丝群体**，但此用户是例外。 |
| 5 | Weibo | 6,917,184 | 272,626 | **6.6M** | 907 | 2,426 | 真实粉丝量大但发帖少，kNN找到发帖相近的普通用户。 |
| 6 | Twitter | 1,001 | 1,580 | **579** | 2,022 | 3,013 | 小用户，误差较小。kNN找到了同量级用户。 |
| 7 | Weibo | 8,450 | 12,341 | **3,891** | 1,378 | 15,088 | 中等用户，误差在可接受范围内。 |
| 8 | Twitter | 543 | 1,891 | **1,348** | 0 | 0 | 小号但无好友无发帖。kNN无有效特征可以匹配。 |
| 9 | Weibo | 336,879 | 186,887 | **150K** | 4,203 | 14,912 | 中型KOL。误差约 44%，在可接受范围。 |
| 10 | Twitter | 3,907 | 4,233 | **326** | 2,338 | 24,542 | 小用户，误差仅 8%。最成功的填充之一。 |

### u13关键发现

1. **极值用户（粉丝数 > 500万）误差最大** — 长尾分布中找不到足够相似的用户
2. **中小用户（粉丝 < 1万）的填充最准** — 同量级样本充足
3. **无特征辅助（好友=0、发帖=0）时填充最差** — 缺少有效维度计算距离
4. **log 尺度上误差更均匀** — 说明 kNN 在对数空间中表现更好


## u13 总结

| 项目 | 说明 |

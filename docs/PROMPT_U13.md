### 任务说明

对 Twitter + Weibo 共约 18,698 个用户，模拟注入 15% 的缺失值，
用两种方法填充并对比：

| 方法 | 原理 | 预期改善 |
|------|------|---------|
| MagnitudeBucketing | 按辅助列的对数量级分桶，取桶内均值 | +3.3% |
| **kNN Imputer** ⭐ | **找特征空间中最相似的 k 个用户，加权平均** | **+65.5%** |

核心思想（你要求的）：
> 一个用户发帖数缺了 → 找发帖数在同量级的其他用户 → 取他们的粉丝数均值来填充

kNN 版本的实现：
1. 自动检测偏态列并做 log 变换（粉丝数跨度 0~千万，直接算距离会被大数主导）
2. 在标准化空间中计算用户间的欧几里得距离
3. 找到 k 个最近邻，按距离倒数加权平均
4. 排除自身（防止数据泄露）

### 输出格式

终端会打印两种方法的对比：

```
  followers_count:
    MagnitudeBucketing    MAE=2139117    Baseline=2187743    +2.2%
    kNN Imputer           MAE=331163     Baseline=2216511    +85.1%
```

关注 `Improve`：越大说明填充越准。kNN 在所有列上显著优于分桶，平均改善 +65.5%。
